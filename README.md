# CANRES Viandes · Boucherie Artisanale & Charcuterie 🥩

> **« La viande comme il faut »**  
> Alliant la tradition colombienne et le savoir-faire québécois.

E-commerce premium especializado en carnicería artesanal, desposte de alta gama y charcutería 100% natural sin aditivos. Arquitectura limpia hexagonal (*Clean Architecture*), optimizada para máxima velocidad y experiencia de compra de lujo.

---

## 🛠️ Stack Tecnológico

- **Frontend**: React 19 + Vite 8
- **Estilos**: Tailwind CSS 3.4 con paleta personalizada de marca (Borgoña oxblood, rojo toro, crema papel carnicero y negro carbón)
- **Rutas**: React Router 7
- **Iconografía**: React Icons (`react-icons/hi2`, `react-icons/fa6`)
- **Arquitectura**: Clean Architecture (Capas: Domain, Application, Infrastructure, Presentation)
- **Persistencia**: Compatible con Supabase (Auth, DB, Storage) o catálogo in-memory demo autónomo
